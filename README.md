# Enactusphere 2.0

The event website for **Enactusphere 2.0**, themed **"Sustain Indian Art"**.

The site introduces the event and covers its story, roadmap, team and FAQ, with registration through Unstop and links to the community on WhatsApp, Instagram, LinkedIn and X.

## About this repository

The whole site is a single exported page, [`index.html`](index.html), built with [Framer](https://www.framer.com/). Its images and fonts load from Framer's CDN, so you need an internet connection to view it properly.

## Viewing it locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Editing

The HTML is generated by Framer, so make content and design changes in the Framer project and export again. Editing the exported file by hand is possible but hard to maintain.

## Deploying

The site is static. Any static host (Vercel, Netlify, GitHub Pages) can serve `index.html` as is.
